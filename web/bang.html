Google OAuth Client ID (của bạn)
Cách lấy Client ID (một lần): vào Google Cloud Console → APIs & Services → Credentials → tạo OAuth client ID loại Web application, bật Google Drive API, thêm địa chỉ trang này vào Authorized JavaScript origins, rồi dán Client ID vào ô trên. Phần mềm chỉ xin quyền drive.file (chỉ truy cập tệp do phần mềm tạo) — dữ liệu nằm trong Google Drive của chính bạn.

Bản quyền gắn với một máy, kiểm tra bằng chữ ký số nên không thể làm giả và hoạt động ngoại tuyến (không gửi dữ liệu đi đâu). Đổi máy/trình duyệt cần cấp key mới.
